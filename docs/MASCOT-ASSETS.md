# Gönderilen maskot seti

Kaynak: Kullanıcının gönderdiği `Downloads.rar`. 18 PNG'den 8'i Nehir Akademi karakteridir; diğer 10 sahne projeye dahil edilmez.

| Kaynak poz | WebP adı | Uygulama durumları |
| --- | --- | --- |
| Ayakta, çantalı | nehir-idle | idle |
| El sallama | nehir-wave | welcome |
| Düşünme | nehir-thinking | thinking |
| İşaret etme | nehir-point | point |
| Zıplayarak kutlama | nehir-celebrate | correct, celebrate, achievement |
| Açık ellerle yardım | nehir-help | help, encourage |
| Defterle çalışma | nehir-study | study |
| Bilgisayarla çalışma | nehir-ai | aiTeacher |

Orijinal PNG'ler `assets/mascot-source` altında korunur. WebP dönüşümü kalite 95 ile yapılmıştır. UI dosya yolu yazmak yerine `config/mascot.ts` eşlemesini kullanır. PWA ikonları yalnızca gönderilen idle pozundan türetilmiştir.
